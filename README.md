# uft-flutter-crud

CRUD com Flutter e Firebase

Objetivo
Desenvolver uma aplicação mobile utilizando Flutter no FlutLab.io e Firebase Firestore, implementando as operações básicas de CRUD (Create, Read, Update e Delete).

Descrição da Atividade
Cada aluno deverá desenvolver um aplicativo com um tema de sua livre escolha, desde que seja possível realizar o gerenciamento de dados utilizando as operações de CRUD.

O objetivo é demonstrar o domínio dos conceitos estudados em sala de aula, incluindo integração com Firebase, manipulação de dados e desenvolvimento de interfaces com Flutter.

Temas
O aluno poderá escolher qualquer contexto para o projeto, tais como:

Agenda de Contatos

Cadastro de Livros

Controle de Estoque

Gerenciamento de Tarefas

Catálogo de Filmes

Cadastro de Clientes

Receitas Culinárias

Cadastro de Alunos

Controle Financeiro

Cadastro de Produtos

Agenda de Eventos

Outros temas de interesse do aluno

Requisitos Obrigatórios
1. Cadastro (Create)
Permitir a inserção de novos registros no sistema.

2. Consulta (Read)
Exibir todos os registros armazenados no Firebase Firestore.

3. Atualização (Update)
Permitir a edição dos dados cadastrados.

4. Exclusão (Delete)
Permitir a remoção de registros com confirmação da ação.

Requisitos Técnicos
Flutter (FlutLab.io)
Utilizar Flutter no ambiente FlutLab.io.

Desenvolver uma interface funcional e organizada.

Utilizar formulários para entrada de dados.

Validar os campos obrigatórios.

Firebase Firestore
Armazenar os dados utilizando Cloud Firestore.

Implementar corretamente todas as operações CRUD.

Utilizar uma coleção adequada ao tema escolhido.

Estrutura Mínima
O projeto deve possuir:

Pelo menos uma coleção no Firebase Firestore.

No mínimo 3 campos de dados por registro.

Uma interface que permita visualizar os registros cadastrados.

Funcionalidade para adicionar novos registros.

Funcionalidade para editar registros existentes.

Funcionalidade para excluir registros.

Todas as operações CRUD devem estar funcionando corretamente.

Observação: O aluno pode implementar todas as funcionalidades em uma única tela ou em múltiplas telas, conforme sua preferência.
